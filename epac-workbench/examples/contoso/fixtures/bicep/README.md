## Deploy

1. Any assignment scoped to `/providers/Microsoft.Management/managementGroups/REPLACE-set-managementGroup-in-manifest` had no target management group — set `managementGroup` on that selection in the manifest and re-build, or remove the selection. Azure rejects this placeholder.
2. Create an OIDC identity with **Resource Policy Contributor** (+ **RBAC Administrator** for role assignments).
3. **Secrets:** `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`, `BICEP_CLIENT_ID`.
4. Run the **Bicep deploy** workflow (`workflow_dispatch`) for an environment (epac-dev); it runs `az deployment mg create` with `main.parameters.<selector>.json`.
