# Company Data Professional — SQL

## Tier rationale

**Professional** — Active security posture for SQL: controls that produce signals an operations team must act on. This tier delivers Microsoft Defender plans surfacing threat signals, vulnerability assessment scanning, network hardening (public access disabled, VNet integration, firewall rules), audit-log and monitoring controls that produce signals for ops teams, and auto-remediation deployments. Together these policies protect against unauthorized network exposure, exploitable vulnerabilities, and undetected privilege misuse. Maps to NIS2 Article 21 (detection & response), ISO 27001 A.12.4 (logging) and A.13 (network security).
