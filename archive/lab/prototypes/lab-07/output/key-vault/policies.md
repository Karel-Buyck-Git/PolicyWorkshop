# Key Vault Policies

## Tier Rationale

**Essential — Cryptographic hygiene and recoverability.**
Key Vault is the trust anchor for every secret, key, and certificate in the subscription; if it is misconfigured the blast radius is the entire application estate. Essential policies enforce the non-negotiables: RBAC-based authorization (rather than legacy access policies), HSM-backed keys, defined expiration and rotation for keys/secrets/certificates, restricted certificate authorities and key sizes, and soft-delete plus purge protection so that an accidental or malicious deletion cannot become permanent data loss. These map directly to CIS Microsoft Azure Foundations Benchmark v2.x section 8 (Key Vault) and ISO 27001 Annex A.10 (cryptography) and A.8.24 (use of cryptography).

**Professional — Network exposure reduction.**
At this tier the vault is no longer addressable from the open internet by default: public network access is disabled or constrained by a firewall allowlist of known IP ranges and trusted Azure services. These are audit/deny/modify policies that require someone to maintain the allowlist and respond when a workload legitimately needs a new path in — that operational ownership is what separates Professional from Essential. This addresses NIS2 Article 21(2)(d) supply-chain security and reduces the credential-theft attack surface that CIS Benchmark §8 calls out.

**Enterprise — Zero-trust connectivity and regulator-grade audit trail.**
Private endpoints and private link bring the vault entirely onto the customer's VNet (no public DNS resolution, no public route), and diagnostic settings stream every key access event into Log Analytics or Event Hub for SIEM ingestion. Together these provide the evidentiary trail and network isolation that regulators expect — ISO 27001 A.12.4 (logging and monitoring), NIS2 Articles 21(2)(b) incident handling and 23 incident reporting, and the CIS Benchmark recommendations on private connectivity for sensitive data services. These policies require Private DNS zones, hub-and-spoke networking, and a downstream SIEM pipeline, which is why they sit at the top tier.
