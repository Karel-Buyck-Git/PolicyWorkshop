### Customer-facing setup guides shipped inside the package (`36f395c`)

Prompted by Karel: the generated package `README.md` *names* the CI/CD prerequisites (secrets,
environments, identities) but has "little to no information" on standing up GitHub/DevOps, or the
Azure/Entra side. Decision (via AskUserQuestion): ship the docs **inside the package** under `docs/`,
**emitted by the generator** — consistent with the #23 delivery boundary (the customer only ever
receives the rendered package, never this repo). Both guides use the drift-proof
**source-of-truth → emitted verbatim → byte-diff CI** pattern already used for `validate-package.py`.

- **GitHub deploy-repo setup guide** — `flows/epac_builder/github_setup.md` → `docs/github/README.md`
  (`_github_setup_doc()` in `package.py`, json flavour, gated with the validator block). Covers
  repo-as-root, **GitHub plan/licensing** (environment required-reviewers need a paid plan on a
  private repo — the sharp edge), **runners** (hosted vs self-hosted), **OIDC** federated-credential
  subjects per job/environment, **environments**, **branch protection + the PR gate**, first-deploy
  order, a checklist, and a mermaid identity→role→job diagram. Self-contained (links only to official
  Azure/GitHub docs).
- **Azure & Entra prerequisites guide** — `flows/epac_builder/azure_requirements.md` →
  `docs/azure/README.md` (`_azure_requirements_doc()`). Covers a collect-up-front value table
  (tenant/subscription/root-MG/dev-MG ids, `managedIdentityLocation`, client ids), management-group
  **scope** + the desired-state deletion warning, subscriptions, **Entra app registrations**,
  least-privilege **RBAC roles** (Reader / Resource Policy Contributor / RBAC Administrator + operator
  setup roles), and **licensing/cost** (Azure Policy free; app regs + workload-identity federation
  need no P1/P2; Machine Configuration Arc per-server + Defender-for-Cloud caveats), and a
  pre-deploy verification checklist.
- Top-level `_epac_readme` updated: Layout line now reads `azure/ & github/ setup guides`, plus two
  pointer lines to the guides. Regenerated the contoso json fixture (only `package/README.md` changed
  + the two new `docs/**/README.md`).
