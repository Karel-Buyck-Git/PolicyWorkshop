# Company Integration Essential — API Management

## Tier rationale

**Essential** — Baseline hygiene for API Management: the non-negotiable controls every deployment should enforce from day one. This tier delivers TLS / HTTPS enforcement preventing in-transit interception, encryption-at-rest with service-managed keys, key and certificate lifecycle hygiene (rotation, expiration, validity), and tagging, SKU, and naming controls for cost and ownership accountability. Together these policies protect against credential theft, unencrypted data exposure, and accidental data loss. Maps to CIS Benchmarks, ISO 27001 Annex A.10 (cryptography) and A.12 (operations).
